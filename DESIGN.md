## Brand & Style

The design system projects high-order operational intelligence, precision execution, and editorial authority. It serves elite search strategists, algorithmic publishers, and autonomous agent fleet managers who direct scaled organic search infrastructure. The interface must feel like an editorial control cockpit: quiet, decisive, surgical, and exceptionally fast.

The design philosophy fuses **Technical Minimalism** with **Tactile Utility**. High-density information hierarchies are rendered with hairline crispness, subtle tonal stepped elevations, and selective optical warmth. The aesthetic avoids consumer-grade playfulness; every line, border, and badge communicates state, throughput, and certainty.

## Colors

The palette relies on deep graphite substrate steps illuminated by warm chalk neutrals, accented by an authoritative kinetic clay orange for primary operations and state progressions.

### Surface Hierarchy
- **Canvas Base (`#0E1015` / Deep Night):** Ground level view frame, outer viewport substrate.
- **Surface Layer 1 (`#16181D` / Deep Graphite):** Primary workspace cards, sidebar structural panels, tool headers.
- **Surface Layer 2 (`#1E222A` / Elevated Graphite):** Hovered items, active table rows, flyout inspector panels.
- **Surface Layer 3 (`#262B35` / Raised Surface):** Modal dialogs, floating context menus, dropdown overlays.

### Core & Accent Palette
- **Clay Orange (`#F2643A`):** Direct kinetic execution, primary actions, fleet dispatch commands, focused cursor rings.
- **Burnt Clay (`#B03E1C`):** Pressed states, high-priority toggle fills, focused tab underlines.
- **Chalk (`#F4F0EA`):** Primary text, metric readouts, active status typography, crisp iconography.
- **Sand (`#E9E4DC`):** Secondary editorial typography, column group headers, muted values.
- **Border Default (`rgba(244, 240, 234, 0.08)`): Hairline card perimeter, table divider rule.
- **Border Strong (`rgba(244, 240, 234, 0.16)`): Focused states, active pane separators.

### Telemetry & Operational State Tokens
- **Operational / Published (`#10B981` / Emerald):** Autonomous generation success, live SERP indexing, healthy run rate. Glow backdrop: `rgba(16, 185, 129, 0.12)`.
- **Degraded / Intervene (`#F59E0B` / Amber):** Model rate limits, content drift detected, human review threshold reached. Glow backdrop: `rgba(245, 158, 11, 0.12)`.
- **Halted / Blocked (`#EF4444` / Rose):** Webhook failure, indexing penalty trigger, prompt execution exception. Glow backdrop: `rgba(239, 68, 68, 0.12)`.

## Typography

The typographic hierarchy differentiates editorial governance from low-level execution logic:
- **Plus Jakarta Sans** delivers refined geometric confidence for section benchmarks, throughput aggregations, and platform navigational anchors.
- **Inter** provides high-density legibility for document titles, narrative draft reviews, contextual audit annotations, and parameter labels.
- **JetBrains Mono** delivers fixed-pitch technical precision for programmatic artifacts: slug routes, canonical hashes, dynamic token insertions, JSON payloads, crawl latencies, and token counters. All numeric readouts in comparative tables must use tabular numerical formatting.

## Layout & Spacing

The layout is built on an adaptive multi-pane fluid workspace calibrated for complex multi-site deployment:
- **Collapsible Global Spine (64px to 240px):** Multi-tenant fleet navigation, engine queue health, API switches.
- **Contextual Work Canvas (Fluid):** Splits conditionally into 12-column configurations or dual-view panes (50/50 editor vs. schema-graph inspector).
- **Inspector Rail (320px to 400px Fixed):** Dynamic SEO entity mapping, meta-tag injection preview, and real-time LLM telemetry.

Breakpoints conform to `768px` (tablet fold down to single stack), `1280px` (desktop standard multi-column), and `1600px` (wide operational command center with permanent three-pane visibility).

## Elevation & Depth

Visual depth is achieved through translucent planar layering, hairline edge definition, and restrained ambient lighting rather than heavy drop shadows:

- **Level 0 (Base Floor):** Deep Night `#0E1015`, zero blur, zero elevation.
- **Level 1 (Card/Container Layer):** Deep Graphite `#16181D` background with `1px solid rgba(244, 240, 234, 0.07)` edge definition.
- **Level 2 (Popovers, Dropdowns, Hovered Modules):** `#1E222A` with backdrop blur of `12px`, border `1px solid rgba(244, 240, 234, 0.12)`, shadow: `0 8px 24px -4px rgba(0, 0, 0, 0.45)`.
- **Level 3 (Modal Orchestrators & Bulk Run Panels):** `#262B35` with `16px` backdrop filter, border `1px solid rgba(244, 240, 234, 0.16)`, shadow: `0 16px 40px -8px rgba(0, 0, 0, 0.65)`.
- **Status Luminescence:** Warning, success, and error badges receive a matching `0 0 8px` drop glow at 25% color opacity to indicate active operational throughput without clutter.

## Shapes

The interface embraces a disciplined **Soft (Scale 1)** border geometry:
- Standard interactive elements (buttons, inputs, dropdown selectors): `4px` (`0.25rem`).
- Cards, data grid enclosures, code panes: `8px` (`0.5rem`).
- Modals, large operational orchestrators: `12px` (`0.75rem`).
- Operational Status Pills: Full pill radius (`9999px`) to create an instant visual distinction between static system containers and transient process nodes.

## Components

### Buttons
- **Primary Kinetic:** Background `#F2643A`, text `#0E1015` (or pure white depending on high contrast compliance; use `#0E1015` bold), border `1px solid rgba(255, 255, 255, 0.1)`. On hover: `#D8532B`. On active: `transform: scale(0.98)` with duration `80ms`.
- **Secondary Neutral:** Background `rgba(244, 240, 234, 0.04)`, text `#F4F0EA`, border `1px solid rgba(244, 240, 234, 0.1)`. On hover: `background: rgba(244, 240, 234, 0.08)`, border color `rgba(244, 240, 234, 0.18)`.
- **Ghost/Destructive:** Background transparent, text `#EF4444`, hover background `rgba(239, 68, 68, 0.08)`.

### Form Fields & Inputs
- Containers use `#121418` fill, `1px solid rgba(244, 240, 234, 0.1)` hairline stroke.
- Focus state activates a precise `1px solid #F2643A` edge ring with `0 0 0 1px #F2643A` without soft spreading halos.
- Code inputs, URL path strings, keyword injection patterns, and regex selectors must render exclusively in `JetBrains Mono`.

### Data Grids & Fleet Tables
- **Header Row:** Text in `Sand` (`#E9E4DC`), uppercase `11px`, `label-meta` spec, letter-spacing `0.05em`, border bottom `1px solid rgba(244, 240, 234, 0.12)`.
- **Data Rows:** Compact height (`40px`), alternating background hover `rgba(244, 240, 234, 0.02)`. Divider lines at hairline `0.5px` opacity.
- **Metric Cells:** Monospaced alignment with baseline right-alignment for numerical confidence scores, SERP rank delta, and token usage counts.

### Status Pills & Engine Badges
- Pill container: Height `20px`, padding `0 8px`, border-radius `9999px`, font `label-code-sm`.
- Status types contain a leading `5px` pulsing indicator dot paired with an inner border of 20% opacity matching the semantic intent (Emerald for Indexed, Amber for Generating, Rose for 4xx/Error).

### Fleet Monitoring Cards
- Container built from Level 1 Surface (`#16181D`) with subtle frosted overlay.
- Top meta bar houses cluster target, autonomy status pill, and throughput sparkline.
- Bottom actions expose direct payload inspection and execution controls.
